# 원본 자료와 로컬 코드

문제 출처는 [Alibaba Terminal-Bench Pro](https://github.com/alibaba/terminal-bench-pro)입니다. 고정 커밋과 파일별 SHA256·크기는 benchmark/tasks.json에 기록합니다. 문제·참고 풀이·검사 원문은 이 저장소나 배포 ZIP에 포함하지 않고 사용 시 원본에서 내려받습니다. 원본 자료의 권리와 이용 조건은 해당 저장소를 따릅니다.

이 저장소는 교육용 로컬 평가기와 명시적 교정 코드를 제공하며, Alibaba 또는 Terminal-Bench의 공식 배포·순위표가 아닙니다. 교정 사항은 BENCHMARK_ERRATA.md에 기록합니다.
